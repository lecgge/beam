# pcap

抓包分析工具(占位),对应技术设计文档 §2 `tools/(bench, pcap 解析)` 与 §3.2 的丢包/乱序/抖动注入测试。

计划能力:

- 解析 QUIC 初始握手,核对 ALPN 是否为 `beam/1`、TLS 1.3 协商结果与证书指纹
- 统计 datagram 的视频/音频/FEC 分片比例(§5 帧头 type 字段:0 视频 / 1 音频 / 2 FEC 冗余)
- 估算 RTT、抖动、丢包率,作为 §8 掉帧率与 E2E 验收的旁证
- 与 §3.2 自写 UDP 代理配合,注入丢包/乱序,验证 FEC 恢复率

规则:抓包文件可能含内网地址与证书指纹,属于敏感数据,只写本地、不提交仓库、不外传。
