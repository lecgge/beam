# Beam tools

辅助工具目录,对应技术设计文档 §2 工程结构中的 `tools/ (bench, pcap 解析)`。

| 目录 | 用途 | 状态 |
|---|---|---|
| `bench/` | 性能基准:抓屏/编码/分包/FEC/解码各阶段耗时基准,输出 P50/P99,用于 §8 性能验收 | 占位 |
| `pcap/` | 抓包分析:解析 QUIC 握手与 datagram 流量,统计丢包/抖动/RTT,辅助 §8 丢包注入测试 | 占位 |

## 约定

- 这些工具不进入 release 产物,不参与 CI 必过项(除 CI 中已有的 `cargo test`/`gradlew test` 覆盖的部分)。
- 所有输出只写本地文件,不外传;性能数字必须来自真实运行,禁止手写。
- 目录内的工具同样遵守 §7 许可证约定:自有代码 MIT OR Apache-2.0,不引入 GPL 代码。
