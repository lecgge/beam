# bench

性能基准工具(占位),对应技术设计文档 §2 `tools/(bench, pcap 解析)` 与 §8 性能基准表。

计划中的基准项(取自 §3 各 crate 的性能预算字段):

| 基准 | 目标(T1 / T2 / T3) | 出处 |
|---|---|---|
| 抓屏 + 取纹理 | ≤1.5 ms / ≤1 ms / ≤1 ms | §3.5 |
| 颜色转换 + 编码 | ≤7 ms / ≤3 ms / ≤2 ms | §3.6 |
| 分包 + FEC 编码 | ≤0.8 ms / ≤0.4 ms / ≤0.3 ms | §3.2 |
| 解码 | ≤8 ms / ≤5 ms / ≤4 ms | §3.10 |
| 端到端 E2E | ≤27 ms / ≤14 ms / ≤11 ms | §8(含帧量化口径) |

规则:基准跑满 10 分钟、报 P99;数字必须来自真实运行,禁止手写或估算填表。
