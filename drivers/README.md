# Beam drivers

Windows 平台驱动与安装脚本,对应技术设计文档 §2 工程结构中的 `drivers/ (虚拟显示器与安装脚本,v1)`。

## 计划内容(全部属于 v1,见 §9 里程碑 M3)

| 项 | 说明 | 依赖 |
|---|---|---|
| `iddcx/` | 虚拟显示器驱动,基于 Indirect Display Driver (IddCx) 框架,让无显示器的场景也能被抓屏 | WDK 签名证书;早期用测试签名 |
| `scripts/` | 主机端安装脚本:安装/卸载驱动、签发与信任主机证书、注册 ViGEmBus(可选组件) | 需管理员权限 |

## 风险与对策(照抄文档 §9 风险表)

- **虚拟显示器驱动签名**:IddCx 自研,早期测试签名;正式分发前需要微软 WHQL/attestation 流程。
- **ViGEmBus 停更**:手柄做可选组件,评估 VHF/UMDF 自研替代。
